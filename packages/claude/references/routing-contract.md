# Router contract

The lead owns the objective, integration, and final report. Dispatch only after
an explicit user request. Give each shared contract one writer. Use only this
worker payload:

```text
GOAL: <outcome>
SCOPE: <paths>
DO NOT: <non-goals>
CHECK: <evidence>
RETURN: paths; check; blocker/risk
```

Keep ordinary returns to five lines. Integrate evidence, run combined checks,
then request a fresh read-only review. Never claim a stop or approval that the
host did not perform.
