# Qwen Code package

The installable extension root is `dynamic-subchat-router/`.

```bash
qwen extensions install ./packages/qwen/dynamic-subchat-router --scope project
```

It provides explicit `/router:*` commands and three focused subagent profiles.
Routine implementation and test profiles use Qwen Code's configured `fast`
model selector. See [the Qwen Code guide](../../docs/qwen-code.md).
